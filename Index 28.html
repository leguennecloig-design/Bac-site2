📐 Dérivation

Fiche du 18/05 · Première · Maths

1. Définitions clés

📌 Fonction dérivable

Une fonction f est dérivable sur un intervalle I si elle est dérivable en tout point de l'intérieur de I.

La fonction dérivée est notée f' : x ↦ f'(x).

📌 Notation de Leibniz

Si y = f(x), on note aussi :

dydx pour f'(x)

📌 Taux d'accroissement

f'(a) = limh→0 f(a+h) − f(a)h

3. Opérations sur les dérivées 🔧

🎯 Les 5 règles à maîtriser

① Somme

(u + v)' = u' + v'

② Produit par une constante

(k·u)' = k·u'

③ Produit

(u·v)' = u'·v + u·v'

④ Inverse

(1v)' = −v'v²

⑤ Quotient

(uv)' = u'·v − u·v'v²

⚠️ Attention

Pour ④ et ⑤ : v ne doit pas s'annuler sur l'intervalle.

Dans le quotient c'est u'v − uv' (signe MOINS !), pas +.

⑥ Composée affine

Si f(x) = g(ax + b) alors f'(x) = a · g'(ax + b)

💡 Exemple

Soit f(x) = 2x³ − 6x − 4

f'(x) = 6x² − 6

4. Variations & extremums 📊

📌 Lien dérivée ↔ variations
  • f'(x) > 0 ⟺ f strictement croissante
  • f'(x) < 0 ⟺ f strictement décroissante
  • f'(x) = 0 ⟺ f constante
📌 Extremum local

f admet un extremum local en a ⟺ f' s'annule ET change de signe en a.

⚠️ Piège majeur

f'(a) = 0 n'implique PAS forcément un extremum !

Ex : f(x) = x³ → f'(0) = 0 mais pas d'extremum (f strictement croissante).

💡 Méthode
  1. Calculer f'(x)
  2. Résoudre f'(x) = 0
  3. Étudier le signe de f'(x)
  4. Dresser le tableau de variations
  5. Extremums = là où f' change de signe
